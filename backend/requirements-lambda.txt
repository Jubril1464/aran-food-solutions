# Runtime dependencies for the AWS Lambda deployment ONLY.

# Deliberately a subset of requirements.txt, not a second source of truth: every
# pin here must match requirements.txt exactly, and
# tests/test_lambda_requirements.py fails the build if they ever drift.
#
# Excluded on purpose, with the reason:
#   uvicorn[standard]  - the ASGI server. Lambda invokes the app through Mangum;
#                        there is no server process. (~10 MB with its extras.)
#   arq, redis         - the local/docker-compose notification queue. On Lambda
#                        the queue is SQS, and app/core/queue.py only imports arq
#                        lazily inside the Redis code path, so it is never
#                        imported here.
#   boto3              - already present in the Lambda Python runtime. Bundling
#                        it would add ~90 MB unzipped (botocore's service JSON)
#                        for no functional gain. See the note in infra/DEPLOY.md
#                        about pinning it if the runtime's version ever matters.
#   pytest, pytest-asyncio, aiosqlite
#                      - test-only.
#
# Keep this list alphabetical-ish by role, matching requirements.txt's order, so
# a diff between the two files is readable.
